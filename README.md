# factory-sandbox

Target repo for the AI Factory's end-to-end runs. See `CLAUDE.md` for conventions and `.factory.yaml` for the
commands the factory runs. Try it: `./gradlew check`.

Starter tickets for the factory (put `repo: <owner>/factory-sandbox` in the description):
- "Add a README badge for Java 21" (size S, docs only)
- "Add `DELETE /greetings/{id}`" (size S, one module)
- "Add a `farewell` module mirroring `greeting`" (size M, new module + changeSet)
